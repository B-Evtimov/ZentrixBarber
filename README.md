# ZentrixBarber

## About
The app is aimed at barbershops as it's for making bookings and in this way automates the whole process instead of calling and spending 20 minutes on it and disrupting their work.

## Features
Choice of barbers, services by category, booking an appointment, managing appointments 

## Technologies
- ASP.NET Core MVC (.NET 10)
- Entity Framework Core
- Microsoft SQL Server
- Bootstrap 5
